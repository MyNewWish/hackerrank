⭐ GitHub (free & open source): https://github.com/MyNewWish/hackerrank

I failed my Stripe online assessment, so I built the practice environment I wish I'd had: a local, HackerRank-style app for Python with a timer, an empty editor, sample tests and hidden tests. It runs completely offline on your own machine, for free.

Why I built this:
1. The real test starts from an empty file. There's no stub, so you parse stdin and print the exact output yourself.
2. I had never practised under real conditions: a timer running, sample tests, hidden tests and exact-match output.
3. Most realistic timed practice sits behind a paywall.

What you get:
🖥️ A HackerRank-like screen: a stopwatch, an empty editor with Python completion, Run on the samples, Submit on the hidden tests, and graded results for each part
📚 14 Stripe-style starter questions: long, multi-part parsing and data-processing problems (payments, ledgers, routing, fraud rules, invoices)
🔍 A line-by-line diff of expected vs. your output, plus a custom stdin runner
✅ Reference solutions to compare with after your timed attempt
🤖 Add any question with AI: paste problem text or a URL into Claude Code, Codex or any coding agent, and the add-question skill builds the statement, tests and a reference solution

cd hackerrank/app
bun install
bun run dev
